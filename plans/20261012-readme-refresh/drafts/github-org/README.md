# HandLive/.github

[![License: Apache-2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

Organization-level configuration, profile overview, and default community health files for the [HandLive](https://github.com/HandLive) open-source project.

## Contents

- **`profile/`** — Organization profile displayed on [github.com/HandLive](https://github.com/HandLive) (`README.md`, `README.vi.md`).
- **`CONTRIBUTING.md` / `CONTRIBUTING.vi.md`** — Guidelines for contributors, PR workflows, small commits, and Developer Certificate of Origin (DCO) sign-off (`git commit -s`).
- **`CODE_OF_CONDUCT.md` / `CODE_OF_CONDUCT.vi.md`** — Community participation standards and expectations.
- **`SECURITY.md` / `SECURITY.vi.md`** — Coordinated vulnerability disclosure policy and reporting process.
- **`ISSUE_TEMPLATE/`** & **`PULL_REQUEST_TEMPLATE.md`** — Standard issue forms and pull request templates across repositories.

Repositories without their own community health files automatically inherit these organization defaults.
