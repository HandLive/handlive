# HandLive/.github

[![License: Apache-2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

Cấu hình cấp tổ chức, trang giới thiệu tổ chức và các file sức khỏe cộng đồng mặc định cho dự án mã nguồn mở [HandLive](https://github.com/HandLive).

## Nội dung

- **`profile/`** — Trang giới thiệu tổ chức hiển thị trên [github.com/HandLive](https://github.com/HandLive) (`README.md`, `README.vi.md`).
- **`CONTRIBUTING.md` / `CONTRIBUTING.vi.md`** — Hướng dẫn đóng góp, quy trình gửi PR, commit nhỏ và ký xác nhận DCO (`git commit -s`).
- **`CODE_OF_CONDUCT.md` / `CODE_OF_CONDUCT.vi.md`** — Tiêu chuẩn và cam kết ứng xử trong cộng đồng.
- **`SECURITY.md` / `SECURITY.vi.md`** — Quy trình báo cáo và chính sách công bố lỗ hổng bảo mật có điều phối.
- **`ISSUE_TEMPLATE/`** & **`PULL_REQUEST_TEMPLATE.md`** — Mẫu chuẩn cho issue và pull request trên toàn bộ các kho lưu trữ.

Các kho lưu trữ chưa có file sức khỏe cộng đồng riêng sẽ tự động thừa hưởng các file mặc định này của tổ chức.
